Asterra Engine

A small C64 BASIC engine exploring tile worlds, independently moving characters and reusable adventure systems.

Status
In development · archived prototype
Build
Test slice v0.2 · archived build
Platform
Commodore 64 · C64 BASIC

Inside the project

  • Test slice includes map movement, an independently timed wandering NPC and combat.
  • Visibility experiments print a render list; they do not draw a finished first-person dungeon.
  • The design proposes modular content, world time, dialogue, quests, shops and save/load. Those are design goals, not a verified feature list.

Controls

Test slice: W/A/S/D to move, Q to quit, 1–3 in combat. Visibility v1 uses C64 cursor codes; v2/v3 use W/A/S/D.

Development notes

The two disk images contain the same ASTERRA program. Both originals are retained. The design calls for proving a tiny test world before building the full adventure; engine capability and compatibility testing remain in progress.
