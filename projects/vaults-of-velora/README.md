# The Vaults of Velora

Wash ashore on Velora, choose a hero and explore a mysterious island in this early Commodore 64 RPG prototype.

Status: In development. Build: FULL-PROTOTYPE-v2 · archived build.

The full prototype is recovered from the uploaded archive. It has been inspected as BASIC program data, but has not yet passed emulator playtesting. This is not a complete adventure.

## Controls

W/A/S/D to move; Q to quit. Choose a hero with 1–3 and use 1–3 in combat.

## Run

Open a PRG with a C64 emulator's program/autostart loader. For a D64, attach to drive 8, enter `LOAD"*",8,1`, then `RUN`. The .bas file is text source, not a binary autostart program. C64 Ultimate compatibility has not been tested.

Original binaries in downloads/ are authoritative and unmodified. listings/ contains inspection text, not round-trip source.
