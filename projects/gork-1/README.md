# GORK 1

Find the golden key and escape the Ruins of the Forgotten Vault in a procedural Commodore 64 dungeon prototype.

Status: In development. Build: v2 · archived filename.

An archived prototype, inspected as BASIC program data. Emulator compatibility and a complete escape run still need testing. The working title is taken from the build.

## Controls

W/A/S/D to move; Q to quit. In combat: F to fight, P to parry, R to run.

## Run

Open a PRG with a C64 emulator's program/autostart loader. For a D64, attach to drive 8, enter `LOAD"*",8,1`, then `RUN`. The .bas file is text source, not a binary autostart program. C64 Ultimate compatibility has not been tested.

Original binaries in downloads/ are authoritative and unmodified. listings/ contains inspection text, not round-trip source.
