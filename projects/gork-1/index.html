GORK 1

Find the golden key and escape the Ruins of the Forgotten Vault in a procedural Commodore 64 dungeon prototype.

Status
In development · archived prototype
Build
v2 · archived filename
Platform
Commodore 64 · C64 BASIC

Inside the project

  • A 20 × 20 maze generated with a backtracking algorithm and extra loop connections.
  • Exploration, gold, a key and a locked exit.
  • Fight, Parry or Run combat; scratch-memory storage instead of arrays.

Try the archived builds

Download a build and open it in a Commodore 64 emulator or transfer it to compatible hardware. Browser play is not yet configured.

  • GORK1_v2.prg

Controls

W/A/S/D to move; Q to quit. In combat: F to fight, P to parry, R to run.

Development notes

An archived prototype, inspected as BASIC program data. Emulator compatibility and a complete escape run still need testing. The working title is taken from the build.
