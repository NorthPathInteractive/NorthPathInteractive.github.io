# North Path Interactive repository instructions

Read and follow the Publishing standard and Current rollout sections in [README.md](README.md) before changing or publishing this site or a project linked from it.

Every published change must have a changelog entry in the same commit. Project pages must link to their authoritative changelog and provide a short What's New summary. Keep applicable version labels consistent. Record shared site changes in the root CHANGELOG.md.

Dungeon 21 is the current pilot. Do not reconstruct histories, backfill changelogs, or bulk-update versions for other projects until Steve authorizes that work after reviewing the pilot. Future explicitly authorized project updates still follow the publishing standard.

Preserve unrelated work and existing changelog history. Verify claims and links before reporting publication as live.
